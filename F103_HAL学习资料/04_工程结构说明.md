# STM32F103 HAL库 工程结构说明

## 标准CubeMX工程目录结构

```
项目目录/
├── Core/
│   ├── Inc/
│   │   ├── main.h              # 主头文件 (HAL库包含 + 引脚定义)
│   │   ├── gpio.h              # GPIO配置头文件
│   │   ├── stm32f1xx_hal_conf.h # HAL模块使能配置
│   │   ├── stm32f1xx_it.h      # 中断处理头文件
│   │   └── 其他外设的 .h 文件
│   └── Src/
│       ├── main.c              # 主程序 (业务逻辑入口)
│       ├── gpio.c              # GPIO初始化
│       ├── stm32f1xx_hal_msp.c # MSP底层初始化 (时钟/DMA/GPIO)
│       ├── stm32f1xx_it.c      # 中断处理函数
│       ├── system_stm32f1xx.c  # 系统初始化 (勿修改)
│       └── 其他外设的 .c 文件
├── Drivers/
│   ├── CMSIS/
│   │   ├── Include/            # ARM CMSIS核心头文件
│   │   └── Device/ST/STM32F1xx/ # F103设备头文件
│   └── STM32F1xx_HAL_Driver/
│       ├── Inc/                # HAL驱动头文件
│       │   └── stm32f1xx_hal_gpio.h
│       └── Src/                # HAL驱动源文件
│           └── stm32f1xx_hal_gpio.c
└── 工程文件/
    ├── .ioc                    # CubeMX工程文件 (重新配置用)
    └── 编译工程文件
```

## 关键文件说明

### main.h - 主头文件
```c
#ifndef __MAIN_H
#define __MAIN_H

#include "stm32f1xx_hal.h"          // HAL库总入口

// 引脚定义区 (CubeMX自动生成)
#define LED_Pin GPIO_PIN_13
#define LED_GPIO_Port GPIOC
#define KEY_Pin GPIO_PIN_0
#define KEY_GPIO_Port GPIOA

void Error_Handler(void);
#endif
```

### main.c - 主程序
```c
#include "main.h"
#include "gpio.h"
// #include "usart.h"    // 启用其他外设时添加
// #include "tim.h"

// 外部外设句柄声明 (供回调函数使用)
extern UART_HandleTypeDef huart1;
extern TIM_HandleTypeDef htim2;

int main(void)
{
    HAL_Init();                   // 1. HAL初始化 + SysTick
    SystemClock_Config();         // 2. 配置系统时钟
    MX_GPIO_Init();               // 3. 初始化GPIO
    // MX_USART1_UART_Init();     // 4. 初始化其他外设
    // MX_TIM2_Init();

    while (1) {
        // 业务逻辑
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
        HAL_Delay(500);
    }
}
```

### gpio.c - GPIO初始化
```c
void MX_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct = {0};

    __HAL_RCC_GPIOC_CLK_ENABLE();
    __HAL_RCC_GPIOA_CLK_ENABLE();

    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET);

    // PC13: LED 输出
    GPIO_InitStruct.Pin = GPIO_PIN_13;
    GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
    GPIO_InitStruct.Pull = GPIO_NOPULL;
    GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
    HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);

    // PA0: 按键输入 (可选)
    // GPIO_InitStruct.Pin = GPIO_PIN_0;
    // GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
    // GPIO_InitStruct.Pull = GPIO_PULLUP;
    // HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
}
```

## 代码编写区域

### USER CODE 区块规则
```
/* USER CODE BEGIN xxx */
    ← 在这里写你的代码
    CubeMX重新生成时会保留这里的内容
/* USER CODE END xxx */

非 USER CODE 区域:
    ← CubeMX重新生成时会覆盖这里
    不要在这里写业务代码
```

### 常用USER CODE区域
| 位置 | 用途 |
|------|------|
| `USER CODE BEGIN Includes` | 添加自定义头文件 |
| `USER CODE BEGIN PV` | 定义全局变量 |
| `USER CODE BEGIN PFP` | 声明自定义函数 |
| `USER CODE BEGIN WHILE` | 主循环中的业务逻辑 |
| `USER CODE BEGIN 0` | 初始化前的自定义代码 |
| `USER CODE BEGIN 2` | 外设初始化后的自定义代码 |

## 添加新外设的步骤

1. **CubeMX中配置**:
   - 选择外设和引脚
   - 配置参数 (波特率、时钟等)
   - 使能中断 (如需要)
   - 点击 GENERATE CODE

2. **在main.c中初始化**:
   - 添加 `#include "新外设.h"`
   - 在 `main()` 中调用 `MX_新外设_Init()`

3. **实现回调函数**:
   - 在 main.c 或单独文件中实现回调

4. **如需DMA**:
   - 在CubeMX的DMA Settings中添加通道
   - 在 `stm32f1xx_hal_conf.h` 中确保 `HAL_DMA_MODULE_ENABLED` 已定义

### bsp_led.c 示例
```c
#include "bsp_led.h"

void LED_Init(void)
{
    // 假设已在MX_GPIO_Init中配置好PC13
    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET);  // 默认灭
}

void LED_On(void)  { HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET); }
void LED_Off(void) { HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET); }
void LED_Toggle(void) { HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13); }
```
