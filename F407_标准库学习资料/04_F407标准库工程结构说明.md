### 3. system_stm32f4xx.c - 系统初始化
**作用**: 系统时钟初始化

**关键全局变量**:
```c
uint32_t SystemCoreClock = 168000000;  // 系统主频 168MHz
```

**SystemInit()函数**:
```c
void SystemInit(void)
{
    // FPU初始化 (可选)
    #if (__FPU_PRESENT == 1) && (__FPU_USED == 1)
    SCB->CPACR |= ((3UL << 10*2)|(3UL << 11*2));
    #endif
    
    // 时钟初始化
    RCC->CR |= RCC_CR_HSION;
    while (!(RCC->CR & RCC_CR_HSIRDY));
    
    // Flash配置
    FLASH->ACR |= FLASH_ACR_PRFTBE;
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_5WS;
    
    // PLL配置
    RCC->PLLCFGR = 8 | (336 << 6) | (RCC_PLLCFGR_PLLSRC_HSE) | (2 << 16) | (7 << 22);
    
    // 使能PLL
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));
    
    // 总线时钟分频
    RCC->CFGR = (RCC->CFGR & ~(RCC_CFGR_HPRE | RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2))
              | RCC_CFGR_HPRE_DIV1
              | RCC_CFGR_PPRE1_DIV4
              | RCC_CFGR_PPRE2_DIV2;
    
    // 选择PLL作为系统时钟
    RCC->CFGR |= RCC_CFGR_SW_PLL;
    while (!(RCC->CFGR & RCC_CFGR_SWS_PLL));
}
```

## 三、F407标准库 vs F103标准库 差异

| 项目 | F103 StdPeriph | F407 StdPeriph |
|------|---------------|----------------|
| 头文件 | `stm32f10x.h` | `stm32f4xx.h` |
| 外设前缀 | `stm32f10x_xxx.h` | `stm32f4xx_xxx.h` |
| GPIO初始化 | `GPIO_Init()` | `GPIO_Init()` (相同) |
| GPIO模式 | `GPIO_Mode_AF_PP` | `GPIO_Mode_AF` + `GPIO_OType_PP` |
| GPIO速度 | `GPIO_Speed_50MHz` | `GPIO_Speed_50MHz` / `GPIO_Speed_100MHz` |
| GPIO AF | `GPIO_PinRemapConfig()` | `GPIO_PinAFConfig()` (新增) |
| 时钟使能 | `RCC_APB2PeriphClockCmd()` | `RCC_AHB1PeriphClockCmd()` / `RCC_APB2PeriphClockCmd()` |
| EXTI时钟 | `RCC_APB2Periph_AFIO` | `RCC_APB2Periph_SYSCFG` |
| USART | `USART_Init()` | `USART_Init()` (新增Over参数) |
| TIM | `TIM_TimeBaseInit()` | `TIM_TimeBaseInit()` (相同) |
| ADC | `ADC_Init()` | `ADC_Init()` (新增ChannelCount等) |
| Flash | `FLASH_PageErase()` | `FLASH_EraseSector()` (扇区擦除) |
| Flash编程 | `FLASH_ProgramWord()` | `FLASH_ProgramWord()` / `FLASH_ProgramDoubleWord()` |
| NVIC | `NVIC_Init()` | `NVIC_Init()` (相同) |
| 专用标准库 | `stm32f10x_misc.h` | `stm32f4xx_misc.h` |
| 专用功能 | 无 | ETH / SDIO / FMC / LTDC / RNG / CRYP / HASH / DCMI |

## 四、Keil MDK 工程配置

### 1. 工程设置
- **Target**: STM32F407VETx
- **Device**: STM32F407VETx (Flash: 512KB, SRAM: 192KB)
- **External Crystal**: 8MHz

### 2. 输出设置
- **Output**: 选择输出路径
- **Listing**: 选择列表文件路径
- **User Code Section**: 启用
- **Include OS Code**: 根据是否使用RTOS

### 3. C/C++ 设置
- **Include Paths**:
  - `.\User`
  - `.\Libraries\CMSIS\Device\ST\STM32F4xx\Include`
  - `.\Libraries\CMSIS\Include`
  - `.\Libraries\STM32F4xx_StdPeriph_Driver\inc`
  
- **Define**:
  - `STM32F407xx` (必须)
  - `USE_STDPERIPH_DRIVER` (必须)
  - `STM32F407_48MHz_C8` (可选)

- **Optimization**: Level 2
- **Target ARM Compiler**: ARMAC5 (AC6需调整)

### 4. Linker 设置
- **ROM (IROM)**:
  - Start: 0x08000000
  - Size: 0x00080000 (512KB)
  
- **RAM (IRAM)**:
  - Start: 0x20000000
  - Size: 0x0001FFFF (128KB)
  
  或:
  - Start: 0x20000000
  - Size: 0x0001C000 (112KB, 保留64KB CCM)

### 5. 调试设置
- **Debug**: 选择ST-Link Debugger
- **ST-Link Debugger Settings**:
  - Interface: SWD
  - Clock: Auto
  - 勾选 "Connect under Reset"

// bsp_led.c
#include "bsp_led.h"

void BSP_LED_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStruct;
    
    RCC_AHB1PeriphClockCmd(RCC_AHB1Periph_GPIOF, ENABLE);
    
    GPIO_InitStruct.GPIO_Pin = GPIO_Pin_9 | GPIO_Pin_10;
    GPIO_InitStruct.GPIO_Mode = GPIO_Mode_OUT;
    GPIO_InitStruct.GPIO_Speed = GPIO_Speed_2MHz;
    GPIO_InitStruct.GPIO_OType = GPIO_OType_PP;
    GPIO_InitStruct.GPIO_PuPd = GPIO_PuPd_NOPULL;

    GPIO_SetBits(GPIOF, GPIO_Pin_9 | GPIO_Pin_10);

void BSP_LED_GreenOff(void) { GPIO_SetBits(GPIOF, GPIO_Pin_9); }

## 六、常见问题

### Q1: 如何下载标准库?
A: 从ST官网下载 `STM32F4xx_StdPeriph_Lib` 包，解压后使用。

### Q2: 编译报 "undefined symbol"
A: 检查是否在工程中添加了对应的 `.c` 文件到 Keil 工程组。

### Q3: EXTI中断不触发?
A: 注意F4使用 `SYSCFG` 而不是 `AFIO`:
```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_SYSCFG, ENABLE);
SYSCFG_EXTILineConfig(EXTI_PortSourceGPIOA, EXTI_PinSource0);
```

### Q4: GPIO AF不工作?
A: F4必须显式配置AF:
```c
GPIO_PinAFConfig(GPIOA, GPIO_PinSource6, GPIO_AF_TIM3);
```

### Q5: Flash写入失败?
A: F4使用扇区擦除，注意:
```c
FLASH_EraseSector(FLASH_Sector_6, FLASH_VOLTAGE_RANGE_3);
// 而不是 F103 的 FLASH_PageErase()
```

### Q6: 与HAL库混用?
A: 可以混用但不推荐。注意:
- HAL库使用 `HAL_GPIO_Init()`
- 标准库使用 `GPIO_Init()`
- 两者操作同一寄存器，可能冲突
- 建议选择一种库

### Q7: printf无输出?
A: 检查重定向函数，Keil使用 `fputc`，GCC使用 `__io_putchar`。
