## 第一节：ESP32-S3 硬件参数

### 1.1 芯片规格
| 特性 | 参数 |
|------|------|
| 内核 | Xtensa LX7 双核 |
| 最高主频 | 240MHz |
| 指令集 | 32-bit RISC + 向量指令 |
| Flash | 外部 SPI Flash（常见 8MB/16MB/32MB） |
| PSRAM | 外部 PSRAM（常见 8MB/16MB/32MB） |
| 片上 SRAM | 512KB |
| 片上 ROM | 384KB |
| ULP Coprocessor | RISC-V 32-bit（低功耗协处理器） |
| 电压范围 | 3.0V ~ 3.6V |
| 工作温度 | -40°C ~ 105°C |

### 1.2 无线连接
| 特性 | 参数 |
|------|------|
| Wi-Fi | 802.11 b/g/n 2.4GHz |
| Wi-Fi 速度 | 最高 150Mbps |
| BLE | 5.0（Bluetooth Low Energy） |
| BLE 速度 | 2Mbps (Coded PHY) |
| 天线 | 2 个 PCB 天线或外部天线 |

### 1.4 ESP32-S3 vs ESP32 vs ESP32-C3
| 特性 | ESP32-S3 | ESP32 | ESP32-C3 |
|------|----------|-------|----------|
| 内核 | 双核 Xtensa LX7 | 双核 Xtensa LX6 | 单核 RISC-V |
| 主频 | 240MHz | 240MHz | 160MHz |
| Wi-Fi | b/g/n | b/g/n | b/g/n |
| BLE | 5.0 | 4.2 | 5.0 |
| USB | USB 1.1 | USB 1.1 | 无 |
| LCD | RGB/LCD | RGB/LCD | 无 |
| Camera | DVP | DVP | 无 |
| PSRAM | 支持 | 支持 | 不支持 |
| ULP | RISC-V | 8051 | RISC-V |
| 加密 | 完整 | 完整 | 完整 |
| Flash | 外部 | 外部 | 外部 |
| 价格 | 中等 | 低 | 最低 |

### 2.2 ESP32-S3-WROOM-1 模组引脚图
```
常用 GPIO 分配:
┌─────────────────────────────────┐
│  ESP32-S3-WROOM-1 (38-pin)      │
├─────────────────────────────────┤
│  3V3  → 3.3V 电源                │
│  GND  → 接地                     │
│  EN   → 复位                     │
│  IO4  → BOOT 模式选择           │
│  IO0  → 按键 (BOOT)             │
│  IO2  → LED (部分开发板)        │
│  IO45 → LED (部分开发板)        │
│  IO46 → LED (部分开发板)        │
│  IO5  → I2C SCL                 │
│  IO6  → I2C SDA                 │
│  IO7  → SPI MOSI                │
│  IO8  → SPI MISO                │
│  IO9  → SPI SCK                 │
│  IO18 → UART1 RX                │
│  IO17 → UART1 TX                │
│  IO20 → USB D-                  │
│  IO19 → USB D+                  │
│  IO43 → UART0 TX (调试串口)     │
│  IO44 → UART0 RX (调试串口)     │
└─────────────────────────────────┘

注意:
- GPIO0: 连接 BOOT 按键，低电平进入下载模式
- GPIO45: strapping 引脚，影响启动模式
- GPIO46: strapping 引脚，影响启动模式
- 启动时不要干扰 strapping 引脚！
```

### 2.3 Strapping 引脚（重要！）
```
Strapping 引脚影响启动配置：
├── GPIO0: Boot 模式选择
│   - 低电平：下载模式（UART 下载）
│   - 高电平：Flash 启动
│
├── GPIO3: JTAG Source
│   - 低电平：Internal ROM
│   - 高电平：GPIO
│
├── GPIO45: VDD_SPI 电压
│   - 低电平：3.3V
│   - 高电平：1.8V
│
├── GPIO46: ROM 消息输出
│   - 低电平：正常
│   - 高电平：打印 ROM 消息

注意: Strapping 引脚在上电复位后会被锁存，
     在启动过程中不要改变其状态！
```

## 第三节：VSCode + ESP-IDF 开发环境搭建

### 3.1 安装 ESP-IDF
```
步骤 1：下载 ESP-IDF
  方法 A：使用官方工具（推荐）
    访问 https://dl.espressif.com/dl/esp-idf/
    下载 esp-idf-tools-setup-2.x.exe
    安装到 C:\Espressif\

  方法 B：手动安装
    git clone -b v5.3 --recursive https://github.com/espressif/esp-idf.git
    cd esp-idf
    install.bat esp32s3

步骤 2：配置环境变量
  - IDF_PATH: esp-idf 根目录
  - IDF_TOOLS_PATH: 工具链目录
  - PATH: 添加 esp-idf\tools 路径

步骤 3：验证安装
  idf.py --version
  应输出: ESP-IDF v5.x.x
```

### 3.2 安装 VSCode 插件
```
1. 打开 VSCode
2. 安装插件 "Espressif IDF"
3. 配置插件:
   - IDF_PATH: esp-idf 根目录
   - IDF_TOOLS_PATH: 工具链目录
   - Python 路径: 使用 esp-idf 自带的 Python
   
4. 使用命令面板 (Ctrl+Shift+P):
   - "ESP-IDF: Select Port to Use"
   - "ESP-IDF: Set Espressif Device Target"
   - "ESP-IDF: Build, Flash and Monitor your project"
```

### 3.3 常用命令
```bash
# 使用 ESP-IDF 终端（推荐）
# 在 ESP-IDF 命令提示符中执行

# 创建新工程
idf.py create-project my_project

# 设置目标芯片
idf.py set-target esp32s3

# 配置工程
idf.py menuconfig

# 编译
idf.py build

# 烧录
idf.py -p COM3 flash

# 监视串口
idf.py -p COM3 monitor

# 清除构建
idf.py fullclean

# 配置分区表
idf.py partition_table
```

### 3.4 常用 menuconfig 配置
```
# 芯片配置
idf.py set-target esp32s3

# 串口配置
idf.py menuconfig
  → Serial flasher config
    → Default serial port: COM3
    → Flash baud rate: 921600
    → Monitor baud rate: 115200

# 分区表配置
idf.py menuconfig
  → Partition Table
    → Partition Table: Custom partition CSV file
    → Custom partition CSV file: partitions.csv

# 组件配置
idf.py menuconfig
  → Component config
    → FreeRTOS: 配置任务数量、优先级
    → Driver: GPIO、UART、I2C、SPI 等驱动
    → Network: Wi-Fi、TCP/IP

# 调试配置
idf.py menuconfig
  → Component config
    → ESP System Settings
      → Panic handler behaviour: Print register and halt
      → Core dump: 启用核心转储
```

## 第五节：第一个 ESP32-S3 程序

### 5.1 创建 LED 闪烁程序
```c
// main/main.c
#include "driver/gpio.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

// LED 引脚定义
#define LED_GPIO  GPIO_NUM_48  // ESP32-S3-WROOM-1 模组 LED
// 或 GPIO_NUM_2, GPIO_NUM_45 等

void app_main(void)
{
    // 配置 GPIO
    gpio_config_t io_conf = {
        .pin_bit_mask = (1 << LED_GPIO),
        .mode = GPIO_MODE_OUTPUT,
        .pull_up_en = GPIO_PULLUP_DISABLE,
        .pull_down_en = GPIO_PULLDOWN_DISABLE,
        .intr_type = GPIO_INTR_DISABLE,
    };
    gpio_config(&io_conf);

    // LED 闪烁
    while (1)
    {
        gpio_set_level(LED_GPIO, 1);
        vTaskDelay(pdMS_TO_TICKS(500));
        gpio_set_level(LED_GPIO, 0);
        vTaskDelay(pdMS_TO_TICKS(500));
    }
}
```

### 5.2 串口打印 Hello World
```c
// main/main.c
#include <stdio.h>
#include "driver/gpio.h"
#include "esp_log.h"

static const char *TAG = "MAIN";

void app_main(void)
{
    ESP_LOGI(TAG, "Hello ESP32-S3!");
    ESP_LOGI(TAG, "Chip model: %s", esp_chip_info().model);
    ESP_LOGI(TAG, "Free heap: %lu bytes", esp_get_free_heap_size());
    ESP_LOGI(TAG, "PSRAM size: %d bytes", esp_chip_info().psram_size);
    
    // LED 配置
    gpio_config_t io_conf = {
        .pin_bit_mask = (1 << GPIO_NUM_48),
        .mode = GPIO_MODE_OUTPUT,
        .pull_up_en = GPIO_PULLUP_DISABLE,
        .pull_down_en = GPIO_PULLDOWN_DISABLE,
        .intr_type = GPIO_INTR_DISABLE,
    };
    gpio_config(&io_conf);

    int count = 0;
    while (1)
    {
        gpio_set_level(GPIO_NUM_48, count % 2);
        ESP_LOGI(TAG, "LED state: %d, Count: %d", count % 2, count);
        count++;
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

## 第六节：ESP32-S3 开发注意事项

### 6.1 GPIO 使用注意
```
ESP32-S3 GPIO 使用注意:
1. Strapping 引脚: GPIO0, 3, 45, 46
   - 启动时不要改变这些引脚的状态
   - GPIO45/46 通常用于 LED（部分开发板）
   - GPIO0 通常连接 BOOT 按键
   
2. USB 引脚: GPIO19 (D+), GPIO20 (D-)
   - 这些引脚用于 USB 1.1
   - 不要同时用作普通 GPIO
   
3. Flash/PSRAM 引脚: GPIO26-32
   - 用于外部 Flash 和 PSRAM
   - 不要使用这些引脚！
   
4. GPIO 输出电流: 最大 40mA
   - 建议使用外部驱动电路
   
5. GPIO 输入电压: 0 ~ VDD (3.3V)
   - 不要超过 3.6V
```

### 6.2 Flash 与分区
```
ESP32-S3 Flash 空间:
- 常见: 8MB (64Mbit) 或 16MB (128Mbit)
- ESP-IDF 默认分区表:
  - Bootloader: 448KB
  - Partition Table: 12KB
  - NVS: 24KB
  - PHY Init: 4KB
  - Factory App: 1MB
  - OTA_0: 1MB (如果有 OTA)
  - SPIFFS/LittleFS: 剩余空间

注意:
- 分区表决定了各区域的大小
- 修改分区表需要重新烧录
- OTA 需要 2 个 app 分区
- SPIFFS/LittleFS 用于存储文件
```

### 6.3 FreeRTOS 基础
```
ESP32-S3 使用 FreeRTOS 作为操作系统:

任务创建:
xTaskCreate(task_func, "task_name", stack_size, 
            param, priority, &task_handle);

任务删除:
vTaskDelete(task_handle);  // 或 vTaskDelete(NULL) 删除自身

任务延时:
vTaskDelay(pdMS_TO_TICKS(1000));  // 延时 1 秒

队列:
QueueHandle_t queue = xQueueCreate(len, size);
xQueueSend(queue, &item, portMAX_DELAY);
xQueueReceive(queue, &item, portMAX_DELAY);

信号量:
SemaphoreHandle_t sem = xSemaphoreCreateMutex();
xSemaphoreTake(sem, portMAX_DELAY);
xSemaphoreGive(sem);

事件组:
EventGroupHandle_t group = xEventGroupCreate();
xEventGroupSetBits(group, BIT_0);
xEventGroupWaitBits(group, BIT_0, pdTRUE, pdFALSE, portMAX_DELAY);

注意:
- 优先级: 0 (最低) ~ configMAX_PRIORITIES-1 (最高)
- 堆栈大小: 以字节为单位
- 双核: 可以指定核心 (xTaskCreatePinnedToCore)
```
