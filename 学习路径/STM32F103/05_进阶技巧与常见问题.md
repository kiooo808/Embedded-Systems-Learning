## 第一节：代码优化技巧

### 1.1 编译优化
```
在 Makefile/CMake 中配置：
-O0: 不优化（调试用）
-O1: 基础优化
-O2: 常规优化（推荐）
-O3: 最大优化（可能影响调试）
-OS: 优化代码大小
```

### 1.2 代码层面优化

#### 使用寄存器直接访问（最快速）
```c
// HAL 库（较慢，需要函数调用和参数检查）
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET);

// 标准库（中等）
GPIO_SetBits(GPIOC, GPIO_Pin_13);

// 寄存器直接访问（最快）
GPIOC->BSRR = GPIO_Pin_13;  // 原子操作，直接设置
GPIOC->BSRR = (uint32_t)GPIO_Pin_13 << 16;  // 原子操作，直接复位
```

#### 使用 LL 库（HAL 的轻量级版本）
```c
#include "stm32f1xx_ll_gpio.h"

// LL 库函数更高效
LL_GPIO_SetOutputPin(GPIOC, LL_GPIO_PIN_13);
LL_GPIO_ResetOutputPin(GPIOC, LL_GPIO_PIN_13);
LL_GPIO_TogglePin(GPIOC, LL_GPIO_PIN_13);
uint32_t state = LL_GPIO_ReadInputReg(GPIOA);
```

#### 避免动态内存分配
```c
// 不推荐
char *buf = malloc(100);
sprintf(buf, "Hello");
free(buf);

// 推荐
char buf[100];
sprintf(buf, "Hello");
```

#### 使用查表代替条件判断
```c
// 不推荐
uint8_t GetSegment(uint8_t num)
{
    switch(num)
    {
        case 0: return 0x3F;
        case 1: return 0x06;
        case 2: return 0x5B;
        // ...
    }
}

// 推荐
const uint8_t segment_map[10] = {
    0x3F, 0x06, 0x5B, 0x4F, 0x66,
    0x6D, 0x7D, 0x07, 0x7F, 0x6F
};
uint8_t GetSegment(uint8_t num)
{
    return segment_map[num];
}
```

#### 内联函数与宏
```c
// 宏（完全展开，无开销）
#define GPIO_PIN_SET_HIGH(port, pin)  ((port)->BSRR = (pin))
#define GPIO_PIN_SET_LOW(port, pin)   ((port)->BSRR = (uint32_t)(pin) << 16)

// 内联函数（编译器决定是否展开）
__STATIC_INLINE void LED_Toggle(void)
{
    GPIOC->ODR ^= GPIO_PIN_13;
}
```

### 1.3 存储优化

#### 变量存储位置
```c
// 放在 SRAM（默认）
uint8_t buffer[256];  // 256 bytes SRAM

// 放在 CCM（Core Coupled Memory，仅 M3/M4 有）
__attribute__((section(".ccm"))) uint8_t buffer[256];

// 放在 Bit-Band 区（位操作映射）
// 地址 0x20000000~0x200FFFFF 映射到 0x22000000 开始
```

#### Const 数据放 Flash
```c
// 默认 const 数据在 Flash
const char *greeting = "Hello World";

// 显式指定
__attribute__((section(".rodata"))) const uint16_t sine_table[256] = { ... };
```

#### 动态调整栈大小
```c
// startup_stm32f103xb.s 中
// 调整栈大小
Stack_Size      EQU     0x400   // 1KB（默认）
Stack_Mem       SPACE   Stack_Size

// 或使用代码
#define STACK_SIZE  256*4  // 256 words = 1KB
```

## 第二节：低功耗设计

### 2.1 STM32F103 低功耗模式

| 模式 | 功耗 | 唤醒源 | 唤醒时间 |
|------|------|--------|----------|
| Run | ~30mA | - | - |
| Sleep | ~10mA | 任意中断 | 0.1us |
| Stop | ~2uA | EXTI/WKUP | 10us |
| Standby | ~1uA | WKUP/RTC | 10ms |

### 2.2 HAL 库低功耗配置
```c
// 进入 Sleep 模式
void Enter_Sleep_Mode(void)
{
    HAL_PWR_EnterSLEEPMode(PWR_SLEEPENTRY_WFI);
}

// 进入 Stop 模式
void Enter_Stop_Mode(void)
{
    PWR_EnterSTOPMode(PWR_STOPENTRY_WFI);
    // 唤醒后恢复时钟
    SystemClock_Config();
}

// 进入 Standby 模式
void Enter_Standby_Mode(void)
{
    // 配置唤醒引脚
    HAL_PWR_EnableWakeUpPin(PWR_WAKEUP_PIN1);
    PWR_EnterSTANDBYMode();
    // 唤醒后系统复位
}
```

### 2.3 低功耗建议
1. 不用时关闭外设时钟
```c
__HAL_RCC_USART1_CLK_DISABLE();
__HAL_RCC_SPI1_CLK_DISABLE();
```

2. 使用中断代替轮询
```c
// 不推荐
while (!HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0));

// 推荐
HAL_NVIC_EnableIRQ(EXTI0_IRQn);
// ... 进入低功耗
HAL_PWR_EnterSLEEPMode(PWR_SLEEPENTRY_WFI);
// 唤醒后在 ISR 中处理
```

3. 关闭不需要的 GPIO
```c
// 配置为模拟输入以降低功耗
GPIO_InitTypeDef cfg = {0};
cfg.Pin = unused_pins_mask;
cfg.Mode = GPIO_MODE_ANALOG;
HAL_GPIO_Init(GPIOA, &cfg);
```

4. 使用 RTC 定时唤醒
```c
#include "stm32f1xx_hal_rtc.h"

// 配置 RTC 闹钟
RTC_AlarmTypeDef alarm = {0};
alarm.AlarmTime.Hours = 1;
alarm.AlarmTime.Minutes = 0;
alarm.AlarmTime.Seconds = 0;
HAL_RTC_SetAlarm(&hrtc, &alarm, RTC_FORMAT_BIN);
HAL_RTC_RegisterCallback(&hrtc, HAL_RTC_ALARM_EVENT_CBn, RTC_AlarmCallback);
```

### 2.4 功耗测试
```
1. 连接电流表（串联在电源回路）
2. 记录各模式电流：
   - 运行模式：~30mA
   - Sleep：~10mA  
   - Stop：~2uA
   - Standby：~1uA
3. 根据功耗调整代码
```

## 第三节：RTOS 基础（FreeRTOS）

### 3.1 FreeRTOS 移植

#### 获取源码
```
1. 从官网下载 FreeRTOS
2. 选择 port: GCC/ARM_CM3
3. 将源码加入工程
```

#### CubeMX 配置
```
1. 打开 CubeMX
2. Middleware → FREERTOS
3. 勾选 Enable
4. 配置参数：
   - TOTAL_HEAP_SIZE: 10000
   - MAX_PRIORITIES: 5
   - MINIMAL_STACK_SIZE: 128
```

### 3.2 任务管理
```c
// 创建任务
xTaskCreate(Task_Function, "TaskName", 256, NULL, 1, NULL);

// 创建静态任务（不使用堆）
static StackType_t task_stack[256];
static StaticTask_t task_buffer;
xTaskCreateStatic(Task_Function, "Task", 256, NULL, 1, 
                  task_stack, &task_buffer);

// 任务函数
void Task_Function(void *param)
{
    while (1)
    {
        // 任务逻辑
        vTaskDelay(pdMS_TO_TICKS(100));
    }
}

// 任务优先级（数字越大优先级越高）
#define PRIORITY_LOW    1
#define PRIORITY_MED    2
#define PRIORITY_HIGH   3
#define PRIORITY_CRIT   4

// 切换任务
taskYIELD();  // 主动让出 CPU
```

### 3.3 任务间通信

#### 队列
```c
// 创建队列
QueueHandle_t data_queue = xQueueCreate(10, sizeof(uint32_t));

// 发送数据
uint32_t data = 42;
xQueueSend(data_queue, &data, portMAX_DELAY);

// 接收数据
uint32_t received;
xQueueReceive(data_queue, &received, portMAX_DELAY);
```

#### 信号量
```c
// 二值信号量
SemaphoreHandle_t binary_sem = xSemaphoreCreateBinary();

// 计数信号量
SemaphoreHandle_t count_sem = xSemaphoreCreateCounting(10, 0);

// 互斥锁
SemaphoreHandle_t mutex = xSemaphoreCreateMutex();

// 取/放
xSemaphoreTake(binary_sem, portMAX_DELAY);
xSemaphoreGive(binary_sem);
```

#### 事件组
```c
EventGroupHandle_t event_group = xEventGroupCreate();

// 设置事件位
xEventGroupSetBits(event_group, BIT_0);

// 等待事件位
EventBits_t bits = xEventGroupWaitBits(event_group, BIT_0 | BIT_1,
                                        pdTRUE, pdFALSE, portMAX_DELAY);

if (bits & BIT_0) { /* 事件0 发生 */ }
if (bits & BIT_1) { /* 事件1 发生 */ }
```

#### 软件定时器
```c
TimerHandle_t timer = xTimerCreate("Timer", pdMS_TO_TICKS(1000),
                                    pdTRUE, 0, TimerCallback);

xTimerStart(timer, 0);
xTimerStop(timer, 0);

void TimerCallback(TimerHandle_t timer)
{
    // 定时执行
}
```

### 3.4 注意事项
1. 中断中只使用 `FromISR` 版本 API
```c
void EXTI0_IRQHandler(void)
{
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    xSemaphoreGiveFromISR(binary_sem, &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}
```

2. 不要在中断中使用阻塞函数
3. 任务栈要足够大（建议 ≥ 256 words）
4. 优先级分配：
   - 中断 > 高优先级任务 > 中 > 低
   - 避免所有任务相同优先级

## 第四节：常见编译问题解决

### 4.1 头文件找不到
**错误**: `xxx.h: No such file or directory`

**解决方案**:
1. 确认头文件路径
2. 在 CMakeLists.txt 中添加 include 目录
3. 使用 `#include "local.h"`（引号包含本地）
4. 使用 `#include <system.h>`（尖括号包含系统）

### 4.2 链接错误
**错误**: `undefined reference to 'HAL_Init'`

**解决方案**:
1. 确认源文件已加入编译
2. 检查 CMakeLists.txt 中的 SRCS 列表
3. 检查编译选项（`-DSTM32F103xB -DUSE_HAL_DRIVER`）
4. 检查链接脚本

### 4.3 重定义错误
**错误**: `multiple definition of 'SystemClock_Config'`

**解决方案**:
1. 检查是否重复包含源文件
2. 确认只有一个 `main` 函数
3. 使用 `static` 限制函数作用域
4. 检查 CubeMX 生成代码的 USER CODE 区域

### 4.4 标志位错误
**错误**: `#error "Unknown FPU configuration"`

**解决方案**:
1. STM32F103 没有 FPU，添加 `-mfpu=none`
2. 检查 STM32F103C8Tx_FLASH.ld 链接脚本
3. 确认编译器选项正确

### 4.5 编译速度慢
**解决方案**:
1. 使用 SSD 存储工程
2. 关闭杀毒软件实时扫描 build 目录
3. 增加并行编译：`make -j8` 或 `cmake --build build -j 8`
4. 避免深层嵌套头文件
5. 使用预编译头（可选）

## 第五节：常见下载/调试问题

### 5.1 ST-Link 连接失败
**错误**: `Cannot connect to target`

**解决方案**:
1. 检查接线（SWDIO/SWCLK/GND）
2. 更换 USB 线和端口
3. 按住 BOOT0 键再连接
4. 检查 ST-Link 驱动
5. 尝试降低 SWD 频率

### 5.2 烧录后无反应
**解决方案**:
1. 检查时钟配置（外部晶振是否正确）
2. 确认启用了调试接口
3. 尝试全片擦除后重新烧录
4. 检查是否进入了低功耗模式
5. 使用 STM32CubeProgrammer 擦除并烧录

### 5.3 程序卡在 HardFault
**常见原因**:
1. 空指针解引用
2. 数组越界
3. 栈溢出
4. 中断优先级配置错误
5. Flash 访问错误

**调试方法**:
1. 在 HardFault_Handler 打断点
2. 查看堆栈回溯
3. 检查 MSP/RSP 寄存器
4. 增加防御性检查

### 5.4 UART 无输出
**解决方案**:
1. 确认 printf 重定向代码
2. 检查波特率配置
3. 确认 GPIO 复用配置
4. 检查是否启用了 USART 时钟
5. 尝试用示波器/逻辑分析仪看 TX 引脚

### 5.5 ADC 读数不准
**解决方案**:
1. 检查参考电压（3.3V ± 5%）
2. 检查采样时间（建议 ≥ 239.5 cycles）
3. 进行 ADC 校准
4. 加滤波（滑动平均/中值滤波）
5. 检查输入阻抗（源阻抗过高需缓冲）
