## 第一节：STM32F407VET6 硬件参数

### 1.1 芯片规格
| 特性 | 参数 |
|------|------|
| 内核 | ARM Cortex-M4（支持 FPU 和 DSP） |
| 最高主频 | 168MHz |
| Flash | 512KB（扇区结构） |
| SRAM | 192KB（112+64+16 KB） |
| 封装 | LQFP100 |
| 电压范围 | 1.8V ~ 3.6V |
| 工作温度 | -40°C ~ 85°C |

### 1.2 外设资源
| 外设 | 数量 | F103 对比 |
|------|------|-----------|
| GPIO | 140+ | 37 |
| USART | 6 | 3 |
| TIM | 14+ | 7 |
| ADC | 3 (12-bit) | 2 |
| SPI | 6 | 2 |
| I2C | 4 | 2 |
| CAN | 2 | 1 |
| USB | USB OTG FS | USB FS |
| ETH | 10/100 MAC | 无 |
| SDIO | 1 | 无 |
| LCD-TFT | 支持 | 无 |
| 以太网 | 有 | 无 |
| 摄像头 | DVP 接口 | 无 |
| 加密 | AES/DES/SHA | 无 |
| AI | 向量指令 | 无 |

### 1.3 F407 Flash 结构（重要区别）
```
F103: 页擦除（Page = 1KB 或 2KB）
F407: 扇区擦除（Sector）

F407VET6 扇区结构（512KB）:
Sector 0:  0x08000000 - 0x08003FFF (16KB)
Sector 1:  0x08004000 - 0x08007FFF (16KB)
Sector 2:  0x08008000 - 0x0800BFFF (16KB)
Sector 3:  0x0800C000 - 0x0800FFFF (16KB)
Sector 4:  0x08010000 - 0x0801FFFF (64KB)
Sector 5:  0x08020000 - 0x0803FFFF (128KB)
Sector 6:  0x08040000 - 0x0805FFFF (128KB)
Sector 7:  0x08060000 - 0x0807FFFF (128KB)
```

### 1.4 F407 时钟树（更复杂）
```
F103: 简单时钟（HSE/HSI + PLL）
F407: 多时钟源 + 多路 PLL

时钟源:
├── HSE: 外部高速晶振（8MHz）
├── HSI: 内部高速（16MHz）
├── LSE: 外部低速晶振（32.768kHz）
├── LSI: 内部低速（32kHz）
└── PLL: 锁相环

主 PLL 配置:
  PLLM = 8 (HSE 分频)
  PLLN = 336 (倍频)  
  PLLP = 2 (主输出)
  → SYSCLK = 168MHz

总线时钟:
  AHB = 168MHz (最大)
  APB1 = 42MHz (最大 42MHz)
  APB2 = 84MHz (最大 84MHz)

注意: 当 APB1/APB2 分频时，定时器时钟会自动倍频！
  APB1 = 42MHz → TIM2-TIM7, TIM12-TIM14 = 84MHz
  APB2 = 84MHz → TIM1, TIM8, TIM9-TIM11 = 168MHz
```

### 1.5 F407 GPIO 差异
```c
// F103 GPIO 配置
gpio_config_t conf = {
    .pin_bit_mask = (1 << pin),
    .mode = GPIO_MODE_OUTPUT_PP,
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
    // 没有 Speed 字段（速度隐含在模式中）
};

// F407 GPIO 配置（新增 Speed 和更灵活的 OType）
gpio_config_t conf = {
    .pin_bit_mask = (1 << pin),
    .mode = GPIO_MODE_OUTPUT_PP,
    .speed = GPIO_SPEED_FREQ_MEDIUM,  // 新增：LOW/MEDIUM/HIGH/VERY_HIGH
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};

// F407 速度选项
GPIO_SPEED_FREQ_LOW       // < 2MHz
GPIO_SPEED_FREQ_MEDIUM    // < 25MHz
GPIO_SPEED_FREQ_HIGH      // < 50MHz
GPIO_SPEED_FREQ_VERY_HIGH // < 100MHz (F4 新增)

// F407 GPIO 模式更丰富
GPIO_MODE_OUTPUT_OD   // 开漏输出
GPIO_MODE_OUTPUT_PP   // 推挽输出
GPIO_MODE_INPUT       // 输入
GPIO_MODE_AF_OD       // 复用开漏
GPIO_MODE_AF_PP       // 复用推挽
GPIO_MODE_ANALOG      // 模拟
```

## 第二节：F407 开发板常用引脚

### 2.1 NUCLEO-F407ZG (常用开发板)
```
LED:
- LD1 (Green): PA5
- LD2 (Blue): PA0  
- LD3 (Red): PB0

按键:
- B1 (User): PA0  (与 LD2 共用！)
- B2 (Reset): NRST

调试:
- ST-Link: SWDIO/SWCLK/GND

常用外设引脚:
- USB OTG: PA9(VBUS), PA11(ID), PA12(DP)
- Ethernet: PA1, PA2, PA7, PC1-PC3, PD3-5
- UART3 (Virtual COM): PD8(TX), PD9(RX)
- I2C: PB6(SCL), PB7(SDA)
- SPI1: PA5(SCK), PA6(MISO), PA7(MOSI)
- ADC: PA0-PA7, PB0-PB1
- DCMI: PA6(PIXCLK), PH7(HSYNC), PH11(VSYNC) + Data Bus
```

### 2.2 最小系统板
```
推荐外设引脚分配:
- LED: PE2/PE3 (或 PA5)
- KEY: PE0 (WKUP)
- USART3: PD8(TX), PD9(RX) - 通过 USB-TTL 连接
- I2C1: PB6(SCL), PB7(SDA)
- SPI1: PA5(SCK), PA6(MISO), PA7(MOSI)
- ADC1: PA0 (CH0)
- SDIO: PC8-PC11 + PD2
```

## 第三节：从 F103 迁移到 F407

### 3.1 关键变化点

| 项目 | F103 → F407 | 代码修改 |
|------|-------------|----------|
| 头文件 | `stm32f1xx_hal.h` → `stm32f4xx_hal.h` | 修改 include |
| 芯片选择 | `STM32F103xB` → `STM32F407xx` | CubeMX 中选择 |
| 时钟配置 | 72MHz → 168MHz | CubeMX 自动配置 |
| GPIO 速度 | 无 → 必须设置 | 添加 `.speed` 字段 |
| GPIO 模式 | 8 种 → 更多 | 检查代码兼容性 |
| Flash 擦除 | `FLASH_PageErase` → `FLASH_Erase_Sector` | 使用扇区擦除 |
| 中断优先级 | 相同 | 相同 |
| FPU | 无 | 需要启用（可选） |
| ADC 结构 | `ADC_InitTypeDef` → `ADC_InitTypeDef` | 新增 `ChannelCount` 字段 |
| 外部中断 | EXTI 配置方式变化 | `SYSCFG` 替代 `AFIO` |

### 3.2 FPU 启用（F407 独有）
```c
// 在 SystemClock_Config() 后添加

// 方式 1：直接配置寄存器
SCB->CPACR |= ((3UL << 10*2)|(3UL << 11*2));
// CP10 = 第 10 位, CP11 = 第 11 位
// 使能 FPU 访问

// 方式 2：使用 HAL 函数（部分版本支持）
HAL_SYSCFG_EnableFPU();

// 方式 3：CubeMX 自动配置
// Project → Settings → Tool Settings → GCC → MCU Settings
// 勾选 "FPU: Single Precision"
// 编译器选项自动添加: -mfpu=fpv4-sp -mfloat-abi=hard

// 验证 FPU
float result = 1.5f * 2.3f;  // 应该使用硬件 FPU
```

### 3.3 F407 专用外设启用
```c
// 以太网 MAC (HAL 库)
#include "eth.h"
#include "lwip.h"

ETH_HandleTypeDef heth;
MX_ETH_Init();
HAL_ETH_Start(&heth);

// USB OTG
#include "usb.h"
#include "usbd_core.h"
#include "usbd_desc.h"
#include "usbd_cdc.h"

USBD_HandleTypeDef hUsbDeviceFS;
MX_USB_OTG_FS_Init();
USBD_Init(&hUsbDeviceFS, &FS_Desc, DEVICE_FS);
USBD_RegisterClass(&hUsbDeviceFS, &USBD_CDC);
USBD_CDC_Init();

// SDIO
#include "sdmmc_cmd.h"
#include "driver/sdmmc_host.h"

sdmmc_host_init();
esp_vfs_fat_sdmmc_mount("/sdcard", card, &mount_config);

// LCD-TFT (FSMC/FMC)
#include "fmc.h"
// CubeMX 配置 FMC → LCD Parallel Interface
```

## 第四节：F407 CubeMX 配置

### 4.1 创建 F407 工程
1. 打开 STM32CubeMX
2. 选择芯片：`STM32F407VETx`（LQFP100 封装）
3. 配置时钟（推荐 168MHz）
4. 配置外设

### 4.2 F407 推荐时钟配置
```
SYSCLK = 168MHz
  ├── HSE = 8MHz
  ├── PLLM = 8
  ├── PLLN = 336
  ├── PLLP = 2
  └── PLLQ = 7 (USB 48MHz)

AHB Prescaler = /1 → HCLK = 168MHz
APB1 Prescaler = /4 → APB1 = 42MHz (最大 42MHz)
APB2 Prescaler = /2 → APB2 = 84MHz (最大 84MHz)
```

### 4.3 F407 常用外设配置

#### GPIO 配置
```
GPIO:
- PA5: GPIO_LED2 (LD1)
- PA0: GPIO_LED3 (LD2) - 注意：与按键 B1 共用
- PB0: GPIO_LED4 (LD3)
- PE0: KEY (外接按键)
- PE2/PE3: 外接 LED
```

#### USART 配置
```
Connectivity → USART3 → Mode: Asynchronous
- PD8: TX (AF_USART3)
- PD9: RX (AF_USART3)
- 波特率: 115200
- 数据位: 8
- 停止位: 1
- 校验: None
- NVIC: 启用 USART3 global interrupt
```

#### TIM PWM 配置
```
Timers → TIM3 → Channel1 → PWM Generation CH1
- PA6: TIM3_CH1 (AF_TIM3)
- Prescaler: 83 (1MHz, F407 APB1=42MHz, TIM 时钟=84MHz)
- Counter Period: 999 (1kHz)
- Pulse: 500 (50%)
```

#### ADC 配置
```
Analog → ADC1 → IN10 (PC0)
- 分辨率: 12-bit
- 通道数: 1
- 采样时间: 84 cycles
- 转换模式: Single
```

#### Ethernet 配置（可选）
```
Connectivity → ETH → Mode: RMII
- PHY: LAN8720 (地址 0)
- PA1: MII_RX_CLK
- PA2: MII_TXD1
- PA7: MII_RX_DV
- PC1: MII_MDC
- PC2: MII_RX_D0
- PC3: MII_RX_D1
- PD3: MII_TXD0
- PD5: MII_TX_EN
```

### 4.4 F407 USB CDC 配置
```
Connectivity → USB_OTG_FS → Mode: Device (Full Speed)
- PA9: VBUS detection
- PA11: D-
- PA12: D+
- Middleware → USB_DEVICE → CDC (Virtual Port Com Port)
```

### 5.2 F407 vs F103 代码对比

#### GPIO 输出
```c
// F103 HAL
gpio_config_t conf = {
    .pin_bit_mask = (1 << 13),
    .mode = GPIO_MODE_OUTPUT_PP,
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};

// F407 HAL (必须添加 speed)
gpio_config_t conf = {
    .pin_bit_mask = (1 << 5),  // PA5
    .mode = GPIO_MODE_OUTPUT_PP,
    .speed = GPIO_SPEED_FREQ_LOW,  // 必须！
    .pull_up_en = GPIO_PULLUP_DISABLE,
    .pull_down_en = GPIO_PULLDOWN_DISABLE,
    .intr_type = GPIO_INTR_DISABLE,
};
```

#### TIM PWM
```c
// F103: TIM3 时钟 = 72MHz (APB1=36MHz → TIM 自动倍频)
htim3.Init.Prescaler = 71;  // 72MHz/72 = 1MHz

// F407: TIM3 时钟 = 84MHz (APB1=42MHz → TIM 自动倍频)
htim3.Init.Prescaler = 83;  // 84MHz/84 = 1MHz
```

#### 主程序模板
```c
// F407 main.c
#include "main.h"
#include "gpio.h"

void SystemClock_Config(void);

// 可选：FPU 初始化
void FPU_Init(void)
{
    SCB->CPACR |= ((3UL << 10*2)|(3UL << 11*2));
}

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    FPU_Init();  // F407 特有

    MX_GPIO_Init();
    MX_USART3_UART_Init();
    MX_TIM3_Init();
    MX_ADC1_Init();
    MX_USB_OTG_FS_Init();  // F407 特有

    // 启动 PWM
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

    // 主循环
    while (1)
    {
        // F407: 更丰富的外设
        HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_5);
        HAL_Delay(500);
    }
}
```
