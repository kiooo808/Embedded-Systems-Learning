# ESP32-S3 ESP-IDF 工程结构说明

## 一、标准工程目录结构

```
my_esp32s3_project/
├── .vscode/                        # VSCode 配置
│   ├── c_cpp_properties.json        # C/C++ 智能提示
│   ├── launch.json                 # 调试配置
│   └── settings.json               # 项目设置
├── main/                           # 主组件（你的代码）
│   ├── CMakeLists.txt              # 组件注册
│   ├── main.c                      # 主程序入口 (app_main)
│   └── include/
│       └── main.h
├── components/                     # 自定义组件（可选）
│   ├── my_driver/
│   │   ├── include/
│   │   │   └── my_driver.h
│   │   ├── my_driver.c
│   │   └── CMakeLists.txt
│   └── my_service/
│       ├── include/
│       ├── my_service.c
│       └── CMakeLists.txt
├── managed_components/             # 托管组件（自动管理，不要手动修改）
│   └── espressif__esp_http_server/  # 示例：从组件注册表下载
├── CMakeLists.txt                  # 顶层 CMake 文件
├── sdkconfig                       # 项目配置（Kconfig生成）
├── sdkconfig.defaults              # 默认配置（可选）
├── partitions.csv                  # 分区表（可选）
├── README.md                       # 工程说明（可选）
├── Makefile                        # 旧版兼容（可选）
└── build/                          # 编译产物（自动生成）
    ├── config/                     # sdkconfig.h 等
    ├── core/                       # 核心组件
    ├── main/                       # main 组件产物
    ├── bootloader/                 # 引导加载程序
    ├── partition_table/            # 分区表产物
    └── flasher_args.json           # 烧录参数
```

## 二、关键文件详解

### 1. 顶层 CMakeLists.txt
```cmake
cmake_minimum_required(VERSION 3.16)

# 设置 IDF_PATH（通常由环境变量自动处理）
# set(ENV{IDF_PATH} "path/to/esp-idf")

# 导入 ESP-IDF 构建系统
include($ENV{IDF_PATH}/tools/cmake/project.cmake)

# 定义工程名（可自定义）
project(my_esp32s3_project)
```

### 2. main/CMakeLists.txt
```cmake
# 注册 main 组件
idf_component_register(
    # 源文件列表（相对于组件目录）
    SRCS
        "main.c"
        "app_gpio.c"
        "app_uart.c"
    
    # 头文件包含目录（相对于组件目录）
    INCLUDE_DIRS
        "."
        "include"
    
    # 依赖的公共组件（公开依赖）
    REQUIRES
        "driver"           # GPIO, UART, SPI, I2C, ADC, LEDC 等驱动
        "freertos"         # FreeRTOS 内核
        "esp_wifi"         # Wi-Fi 功能
        "esp_netif"        # 网络接口
        "esp_event"        # 事件循环
        "nvs_flash"        # NVS 存储
        "log"              # 日志系统
    
    # 依赖的私有组件（仅本组件使用）
    PRIV_REQUIRES
        "fatfs"            # FAT文件系统
        "spiffs"           # SPIFFS
        "mdns"             # mDNS 服务
        "json"             # cJSON 库
        "mbedtls"          # TLS/加密
)
```

### 3. main/main.c
```c
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
// ... 其他头文件

// app_main 是程序入口，等价于 Arduino 的 setup()
void app_main(void)
{
    ESP_LOGI("main", "ESP32-S3 starting...");
    
    // 初始化代码...
    
    // 创建 FreeRTOS 任务
    xTaskCreate(my_task, "my_task", 4096, NULL, 5, NULL);
}
```

### 4. sdkconfig 文件
`sdkconfig` 是项目核心配置文件，由 `menuconfig` 生成：

```
# 芯片型号
CONFIG_IDF_TARGET="esp32s3"

# 时钟频率
CONFIG_ESP_DEFAULT_CPU_FREQ_MHZ_240=y

# Wi-Fi
CONFIG_ESP_WIFI_ENABLED=y

# 蓝牙
CONFIG_BT_ENABLED=y

# FreeRTOS
CONFIG_FREERTOS_HZ=1000
CONFIG_FREERTOS_MAX_TASK_NAME_LEN=16

# 串口控制台
CONFIG_ESP_CONSOLE_UART_NUM=0
CONFIG_ESP_CONSOLE_UART_BAUDRATE=115200

# Flash
CONFIG_ESPTOOLPY_FLASHSIZE_8MB=y

# 分区表
CONFIG_PARTITION_TABLE_CUSTOM=y
CONFIG_PARTITION_TABLE_CUSTOM_FILENAME="partitions.csv"

# 编译器优化
CONFIG_COMPILER_OPTIMIZATION_SIZE=y

# 断言
CONFIG_COMPILER_OPTIMIZATION_ASSERTIONS_ENABLE=y

# 日志级别
CONFIG_LOG_DEFAULT_LEVEL_INFO=y
```

## 三、组件化开发详解

### 1. 创建自定义组件

#### 目录结构
```
components/my_component/
├── include/
│   └── my_component.h       # 公开头文件
├── my_component.c            # 实现代码
└── CMakeLists.txt            # 组件注册
```

#### CMakeLists.txt
```cmake
idf_component_register(
    SRCS "my_component.c"
    INCLUDE_DIRS "include"
    REQUIRES "driver" "freertos"
)
```

#### 头文件 my_component.h
```c
#pragma once

#include "driver/gpio.h"

#ifdef __cplusplus
extern "C" {
#endif

// 初始化
void my_component_init(void);

// 其他接口
void my_component_do_something(void);

#ifdef __cplusplus
}
#endif
```

#### 源文件 my_component.c
```c
#include "my_component.h"
#include "esp_log.h"

static const char *TAG = "my_component";

void my_component_init(void)
{
    ESP_LOGI(TAG, "Initializing my component...");
    // 初始化代码...
}

void my_component_do_something(void)
{
    ESP_LOGI(TAG, "Doing something...");
}
```

### 2. 组件依赖关系

```
main 组件
  ├── REQUIRES: driver, freertos, esp_wifi, nvs_flash, ...
  ├── PRIV_REQUIRES: fatfs, spiffs, ...
  │
  └── my_component (components/my_component/)
        └── REQUIRES: driver, freertos
```

## 四、编译配置

### 1. 常用 idf.py 命令
```bash
idf.py set-target esp32s3        # 设置芯片
idf.py build                     # 编译
idf.py build flash               # 编译+烧录
idf.py flash                     # 仅烧录
idf.py monitor                   # 串口监视
idf.py menuconfig                # 配置
idf.py fullclean                 # 清除所有产物
idf.py reconfigure               # 重新配置 CMake
idf.py size                      # 查看代码大小
idf.py size-components           # 各组件大小
```

### 2. 编译选项
```bash
# 查看详细编译输出
idf.py build VERBOSE=1

# 只编译某个组件
idf.py reconfigure && idf.py build

# 并行编译（加速）
idf.py build -j 8

# 指定 Python 环境
idf.py build PYTHON_DEPS_CHECKED=1
```

### 3. 常见编译问题

| 问题 | 解决方案 |
|------|----------|
| `xxx.h: No such file` | 在 `CMakeLists.txt` 的 `REQUIRES` 中添加对应组件 |
| `undefined reference to xxx` | 确认 `REQUIRES` 包含实现该函数的组件 |
| `invalid literal suffix` | 修改 `sdkconfig` 中的对应选项 |
| `partition table parse error` | 检查 `partitions.csv` 格式，行尾不要有注释 |
| `hash mismatch` | 删除 `managed_components` 中对应目录让其重新下载 |
| `idf.py not found` | 先执行 `export.ps1` 激活环境 |

## 五、烧录与调试

### 1. 烧录参数
```bash
# 自动检测端口
idf.py -p COM3 flash

# 指定波特率
idf.py -p COM3 -b 921600 flash

# 烧录后自动监视
idf.py -p COM3 flash monitor
```

### 2. 烧录模式
```bash
# 正常模式
idf.py flash

# 深度睡眠唤醒
# GPIO0 低电平进入下载模式
# 或使用 ESP32-S3 的 USB 接口
```

### 3. OpenOCD 调试
```bash
# VSCode 插件配置后可直接 F5 调试
# 或使用命令行：
openocd -f interface/usbmodem.cfg -f target/esp32s3.cfg
```

## 六、版本管理

### 1. ESP-IDF 版本查看
```bash
idf.py --version
# 或
$IDF_PATH/tools/idf.py --version
```

### 2. 组件版本
```bash
# 查看当前组件版本
idf.py reconfigure
# 查看 managed_components 中的版本
cat managed_components/components.yml
```

### 3. 更新组件
```bash
# 更新所有组件
idf.py update-dependencies

# 更新特定组件
idf.py update-component espressif/esp_http_server
```
