# STM32F407VET6 HAL库 学习指南

## 一、F407 vs F103 核心区别

### 硬件资源对比

| 特性 | STM32F103C8T6 | STM32F407VET6 |
|------|---------------|---------------|
| 内核 | Cortex-M3 | Cortex-M4 (支持FPU) |
| 最高主频 | 72MHz | 168MHz |
| Flash | 64KB | 512KB |
| SRAM | 20KB | 192KB (112+64+16) |
| GPIO数量 | 37 | 140+ |
| USART | 3 | 6 |
| TIM | 4+2 | 12+2+2 |
| ADC | 2 (12位) | 3 (12位) |
| SPI | 2 | 6 |
| I2C | 2 | 4 |
| FPU | 无 | 单精度硬件浮点 |
| 以太网 | 无 | 10/100 MAC |
| USB | FS | OTG FS |
| SDIO | 无 | 支持 |
| LCD-TFT | 无 | 支持 |
| 加密 | 无 | AES/DES/SHA |
| 随机数 | 无 | RNG |

### HAL库主要差异

| 对比项 | F103 HAL | F407 HAL |
|--------|----------|----------|
| 头文件 | `stm32f1xx_hal.h` | `stm32f4xx_hal.h` |
| 芯片选择 | `STM32F103xB` | `STM32F407xx` |
| 时钟树 | 简单 (HSE/HSI + PLL) | 复杂 (多时钟源 + 多路PLL) |
| GPIO速度 | 最高50MHz | 最高100MHz |
| 中断优先级 | 16级 | 16级 (相同) |
| FPU初始化 | 不需要 | 需要启用 |
| 电源控制 | 简单 | 需要调压器配置 |

## 二、从F103迁移到F407的关键点

### 1. 时钟系统差异

**F103时钟**: 72MHz (HSE 8MHz × 9 PLL)
**F407时钟**: 168MHz (HSE 8MHz × 168/8 = PLL)

F407有多个时钟源和分频器:
```
时钟源: HSE(8MHz), HSI(16MHz), LSE(32.768kHz), LSI(32kHz)

主PLL: 
  PLLM = 8 (输入分频)
  PLLN = 336 (倍频)
  PLLP = 2 (主输出分频)
  → 168MHz SYSCLK

APB1 = 42MHz (168/4, 最高42MHz)
APB2 = 84MHz (168/2, 最高84MHz)
```

### 2. 新增FPU初始化

```c
// 在 main.c 的 SystemClock_Config() 之后添加:
// 启用FPU (Cortex-M4)
SCB->CPACR |= ((3UL << 10*2)|(3UL << 11*2));  // 使能CP10/CP11

// 或者使用HAL库函数:
HAL_SYSCFG_EnableFPU();  // 需要检查是否有此函数
```

### 3. GPIO配置差异

```c
// F103: 速度选项
GPIO_SPEED_FREQ_LOW       // < 2MHz
GPIO_SPEED_FREQ_MEDIUM    // < 25MHz
GPIO_SPEED_FREQ_HIGH      // < 50MHz

// F407: 新增超高速
GPIO_SPEED_FREQ_VERY_HIGH // < 100MHz (F4新增)
```

### 4. Flash写入差异

```c
// F103: 页大小 1KB/2KB
FLASH_PageErase(address);

// F407: 扇区大小不同 (需按扇区擦除)
// F407VET6扇区结构:
//   Sector 0-3:  16KB each (0x08000000 - 0x0800FFFF)
//   Sector 4:    64KB (0x08010000 - 0x0801FFFF)
//   Sector 5-11: 128KB each
FLASH_Erase_Sector(sector, FLASH_TYPEERASE_SECTOR);
```

### 5. 新增外设

F407新增的外设在CubeMX中可直接启用:
- `ETH` - 以太网MAC
- `USB_OTG_FS` - USB Host/Device
- `SDIO` - SD卡接口
- `LCD_TFT` - LCD显示
- `CRYP` - 加密引擎
- `HASH` - 哈希引擎
- `RNG` - 随机数生成
- `DCMI` - 摄像头接口
- `FMC` - 灵活存储控制器

## 三、GPIO 对比 (F103 → F407)

### F103 HAL写法
```c
__HAL_RCC_GPIOC_CLK_ENABLE();

GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin = GPIO_PIN_13;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Pull = GPIO_NOPULL;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
```

### F407 HAL写法
```c
__HAL_RCC_GPIOC_CLK_ENABLE();

GPIO_InitTypeDef GPIO_InitStruct = {0};
GPIO_InitStruct.Pin = GPIO_PIN_13;
GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
GPIO_InitStruct.Pull = GPIO_NOPULL;
GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_MEDIUM;  // F407常用中速及以上
HAL_GPIO_Init(GPIOC, &GPIO_InitStruct);
```

### GPIO模式对照表 (相同)

| 功能 | F103 HAL | F407 HAL |
|------|----------|----------|
| 输入 | `GPIO_MODE_INPUT` | `GPIO_MODE_INPUT` |
| 推挽输出 | `GPIO_MODE_OUTPUT_PP` | `GPIO_MODE_OUTPUT_PP` |
| 开漏输出 | `GPIO_MODE_OUTPUT_OD` | `GPIO_MODE_OUTPUT_OD` |
| 复用推挽 | `GPIO_MODE_AF_PP` | `GPIO_MODE_AF_PP` |
| 复用开漏 | `GPIO_MODE_AF_OD` | `GPIO_MODE_AF_OD` |
| 模拟 | `GPIO_MODE_ANALOG` | `GPIO_MODE_ANALOG` |
| 上升沿中断 | `GPIO_MODE_IT_RISING` | `GPIO_MODE_IT_RISING` |
| 下降沿中断 | `GPIO_MODE_IT_FALLING` | `GPIO_MODE_IT_FALLING` |

## 四、USART 对比

### 主要区别
- F407有6个USART (USART1-6)
- USART3/UART4/UART5/UART6在APB1上
- F407支持更高的波特率精度

### 配置示例
```c
// F103: 36MHz APB1时钟, 115200波特率
huart2.Init.BaudRate = 115200;

// F407: 42MHz APB1时钟, 115200波特率
// 波特率计算不同, CubeMX自动处理
huart2.Init.BaudRate = 115200;
huart2.Init.OverSampling = UART_OVERSAMPLING_16;  // 过采样设置
```

## 五、TIM 对比

### 定时器资源
- F103: TIM1-8 (高级: TIM1, TIM8)
- F407: TIM1-14 + TIM15-18 (更多定时器)

### PWM配置
```c
// F103: TIM3 CH1 (PA6)
__HAL_RCC_TIM3_CLK_ENABLE();

// F407: TIM3 CH1 (PA6) - 相同语法
// 但F407定时器时钟更高 (84MHz vs 72MHz)
htim3.Init.Prescaler = 83;      // 84MHz / 84 = 1MHz
htim3.Init.Period = 999;        // 1kHz PWM
```

## 六、中断优先级

### 完全相同
```c
// 设置优先级分组
HAL_NVIC_SetPriorityGrouping(NVIC_PRIORITYGROUP_2);

// 设置中断优先级
HAL_NVIC_SetPriority(EXTI0_IRQn, 2, 0);
HAL_NVIC_EnableIRQ(EXTI0_IRQn);
```

### 优先级分组 (Cortex-M4相同)
```
NVIC_PRIORITYGROUP_0: 0抢占 + 4子
NVIC_PRIORITYGROUP_1: 1抢占 + 3子
NVIC_PRIORITYGROUP_2: 2抢占 + 2子 (常用)
NVIC_PRIORITYGROUP_3: 3抢占 + 1子
NVIC_PRIORITYGROUP_4: 4抢占 + 0子
```

## 八、F407开发注意事项

### 1. 时钟配置
- 必须正确配置PLL才能达到168MHz
- APB1最高42MHz, APB2最高84MHz
- 定时器时钟在APB1/APB2分频时自动倍频

### 2. 电源配置
- F407内置调压器, 需在CubeMX中选择
- 低功耗模式需要正确配置

### 3. Flash编程
- 扇区大小不同, 注意擦除边界
- F407写入速度更快 (168MHz)

### 4. 编译选项
- 建议启用FPU编译选项: `-mfpu=fpv4-sp -mfloat-abi=hard`
- 在CubeMX生成的Makefile/CMake中自动配置

### 5. FreeRTOS
- F407资源丰富, 适合运行RTOS
- 建议使用CMSIS-RTOS或FreeRTOS
- 注意栈空间分配 (192KB SRAM足够)
